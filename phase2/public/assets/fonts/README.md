# Prompt fonts

Unmodified files from the official Google Fonts repository, `ofl/prompt`:
https://github.com/google/fonts/tree/main/ofl/prompt

Copyright (c) 2015, Cadson Demak. Distributed under the SIL Open Font License 1.1 included in `OFL.txt`.

The filename suffix is the first eight characters of the upstream Git blob SHA, verified after download:

- Regular 400: `2a736dbba7d0bcb384bc1866516574f96e3d4893`
- Medium 500: `adf72c9f63f02f0d2d456c902eb21d9b26e8b967`
- SemiBold 600: `011a0507ab4e2ae83384acb0185d6593f3c35605`
- Bold 700: `6cdd89b4511127b6d96fbfad26257f63bd5f7a4b`

Only these fingerprinted TTF paths are served by the PHP asset allowlist. Font files are not modified or subsetted. No runtime request to Google Fonts is needed.
