# รายชื่อพื้นที่อ้างอิง

ข้อมูลรายชื่อจังหวัดและอำเภอ/เขต: [Thailand Geography JSON](https://github.com/thailand-geography-data/thailand-geography-json), โดย Joe Takara, MIT License

ดึงข้อมูลวันที่ 12 พฤศจิกายน 2569 และตรึงรุ่นที่ commit `021d18e9a481bc141ea87de4ddeebe843cff2f12`

- `provinces.json`: 77 จังหวัด รวมกรุงเทพมหานคร
- `districts.json`: 928 อำเภอ/เขต รวม 50 เขตกรุงเทพมหานคร
- `LICENSE.txt`: สำเนาใบอนุญาตต้นฉบับ ใส่คำประกาศนี้ในไฟล์ HTML ฉบับส่งมอบด้วย

ตรวจจำนวนภาพรวมเทียบกับเอกสาร [สำนักทะเบียนที่ให้บริการงานทะเบียนทั่วประเทศ กรมการปกครอง ข้อมูล ณ 19 ธันวาคม 2568](https://www.bora.dopa.go.th/wp-content/uploads/2025/12/tabdb_19122568.pdf) ซึ่งระบุ 878 อำเภอและ 50 เขต ไม่ได้อ้างว่าไฟล์ JSON นี้เป็นไฟล์ทางการของกรมการปกครอง

จับคู่รายชื่อด้วยจังหวัดและอำเภอ/เขตพร้อมกัน: รายการที่มีการสมัคร 463 พื้นที่ตรงชื่อครบทั้งหมด ไม่ต้องแก้ชื่อหรือเดาจับคู่ จึงเพิ่มพื้นที่ที่เหลือ 465 แห่งเป็น `[0,0,0]` ในชุดข้อมูลต้นแบบนี้ได้ ยอดรวมทั้งสามรุ่นยังเป็น 628/683/525 รวม 1,836 ทีม

ขั้นตอนสร้างไฟล์จะหยุดหากพบรายการสมัครที่จับคู่ไม่ได้ รหัสซ้ำ จำนวนพื้นที่ไม่ครบ หรือยอดทีมไม่ตรง ห้ามใช้วิธีทิ้งแถวที่จับคู่ไม่ได้แล้วเติมศูนย์ให้ทะเบียนพื้นที่
