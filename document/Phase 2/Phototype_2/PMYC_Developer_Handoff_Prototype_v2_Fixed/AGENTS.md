# AGENTS.md — PMYC ระบบจัดการแข่งขัน

## คำสั่งสำหรับ AI Coding Agent
1. อ่าน `FLOW.md`, `DATA_CONTRACTS.md`, `API_ENDPOINTS.md` และหน้าจอ HTML ก่อนเขียนโค้ด
2. ตรวจระบบการลงทะเบียนเดิมก่อนสร้างตาราง/model ใหม่
3. ใช้ Team / Player / TeamOfficial เดิม ไม่สร้างข้อมูลบุคคลซ้ำ
4. UI และข้อความที่ผู้ใช้เห็นต้องเป็นภาษาไทย
5. ชื่อ class, API endpoint, database field และ code identifier ใช้ภาษาอังกฤษได้
6. ห้ามเดากฎที่ยังไม่ได้รับการยืนยัน

## กฎหลัก
- Stage 1 ระดับอำเภอ: แพ้คัดออก, ระบบสุ่ม, สูงสุด 8 ทีม, คัด 2 ทีม
- Stage 2 ระดับจังหวัด: แพ้คัดออก, ระบบสุ่ม, หาแชมป์จังหวัด
- ออลสตาร์: แมวมองคัดนักกีฬาจากทีมตกรอบ มี Favorite/Candidate/เอกสารโอนย้าย/เจ้าหน้าที่
- Stage 3: พบกันหมด 1 เลก คะแนน 3/2/1/0
- Stage 4: 12 แชมป์โซน, 2 กลุ่ม, รอบรองฯ, ชิงอันดับ 3, รอบชิงฯ

## การจับสลาก
- การสุ่มจริงทำที่ backend
- animation แสดงผลที่ backend ยืนยันแล้ว
- Reset สร้างเวอร์ชันใหม่และเก็บเวอร์ชันเดิม
- บันทึกผู้ดำเนินการ เวลา เหตุผล เวอร์ชัน และ algorithm_version

## เรื่องที่ยังรอยืนยัน
- เกณฑ์ตัดสินเมื่อคะแนนเท่ากัน
- สกอร์ตัวเลขกรณีชนะบาย
- การนับผลยิงจุดโทษใน GF/GA
- จุดที่ปิดสิทธิ์สุ่มใหม่
- จำนวน/โควตาผู้เล่นและเจ้าหน้าที่ออลสตาร์
- กติกาใบเหลือง/ใบแดง/การพักการแข่งขัน
