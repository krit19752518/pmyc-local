# โครงสร้างข้อมูลเชิงแนวคิด

ชื่อ Entity/Field ใช้ภาษาอังกฤษในโค้ด แต่ความหมายสำหรับระบบเป็นดังนี้:

- `Season` ฤดูกาล
- `Competition` รายการแข่งขัน
- `CompetitionParticipant` ทีมเข้าร่วม
- `Draw` รอบ/เวอร์ชันการจับสลาก
- `DrawSlot` ตำแหน่ง A1…An
- `Match` การแข่งขันแต่ละคู่
- `MatchLineup` รายชื่อผู้เล่นของทีมในแต่ละแมตช์
- `MatchResult` ผลการแข่งขัน
- `Zone`, `ZoneProvince`, `ZoneParticipant` ข้อมูลโซน
- `Standing` ตารางคะแนน
- `ScoutFavorite`, `ScoutNote` ข้อมูลแมวมอง
- `AllStarTeam`, `AllStarRosterPlayer`, `AllStarRosterStaff` ทีมออลสตาร์
- `TransferDocument` เอกสารโอนย้าย
- `AuditLog` ประวัติการทำรายการ
