# Mobile QA Checklist

ทดสอบอย่างน้อย:
- 360 × 800
- 390 × 844
- 430 × 932
- Tablet 768 × 1024
- Desktop 1366 × 768

ตรวจสอบ:
- Hamburger เปิด/ปิดเมนูได้
- หน้าไม่เลื่อนซ้าย–ขวาทั้งหน้า
- Table เลื่อนซ้าย–ขวาเฉพาะใน Table container
- Bracket เลื่อนซ้าย–ขวาเฉพาะก้างปลา
- Stage 3 Fixture เลื่อนซ้าย–ขวาเฉพาะ Fixture
- Input ไม่ทำให้ Browser ซูมเข้า
- Card และ Developer Notes ไม่ล้นจอ
- Logo ไม่เกินความกว้างหน้าจอ
