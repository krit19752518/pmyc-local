# แผนผังหน้าจอระบบ PMYC

เปิด `index.html` เพื่อดูสารบัญหน้าจอทั้งหมด

กลุ่มหน้าจอหลัก:
1. ภาพรวม / ตั้งค่าการแข่งขัน / ทีมเข้าร่วม
2. Stage 1–2: จับสลาก ก้างปลา ตารางแข่งขัน รายชื่อผู้เล่น ผลการแข่งขัน
3. แมวมอง / ทีมออลสตาร์
4. Stage 3–4: โซน โปรแกรมพบกันหมด ตารางคะแนน รอบประเทศ
5. เว็บไซต์สาธารณะ
6. ประวัติการทำรายการ / สิทธิ์การใช้งาน
