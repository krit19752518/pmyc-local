# PMYC — ชุดต้นแบบสำหรับทีมพัฒนา (ภาษาไทย)

ชุดนี้ใช้เป็นข้อมูลอ้างอิงให้ทีม UI/UX, Frontend, Backend และ AI Coding Agent พัฒนาระบบจัดการแข่งขันจริง

## หลักการภาษา
- ข้อความที่ผู้ใช้งานเห็นบนหน้าจอเป็นภาษาไทย
- ชื่อโครงการ/คำย่อ เช่น PMYC, U14/U16/U18, Stage 1–4 สามารถคงไว้ได้
- ชื่อไฟล์, API endpoint, database field, code identifier ใช้ภาษาอังกฤษเพื่อความสะดวกในการพัฒนา
- ทุกหน้ามีหัวข้อ **รายละเอียดสำหรับทีมพัฒนา** ระบุวัตถุประสงค์ ข้อมูลที่ใช้ การทำงานหลัก และกฎ/การตรวจสอบ

## วิธีเปิด
เปิด `index.html` ด้วย Chrome/Edge หรือ deploy ทั้งโฟลเดอร์ขึ้น Netlify/GitHub Pages

## เอกสารประกอบ
- `SCREEN_MAP.md` — แผนผังหน้าจอ
- `FLOW.md` — ขั้นตอนการทำงาน
- `DATA_CONTRACTS.md` — โครงสร้างข้อมูลเชิงแนวคิด
- `API_ENDPOINTS.md` — API ที่แนะนำ
- `AGENTS.md` — ข้อกำหนดสำหรับ AI Coding Agent


## Mobile Responsive v3

เวอร์ชันนี้ปรับให้รองรับมือถือจริง ไม่ใช่เพียงการย่อหน้า Desktop

- ที่หน้าจอไม่เกิน 900px เมนูด้านซ้ายเปลี่ยนเป็น Hamburger / Off-canvas Drawer
- Card/Form เปลี่ยนเป็น 1 คอลัมน์
- ตารางยาวเลื่อนซ้าย–ขวาภายใน Card โดยไม่ดันทั้งหน้าให้กว้างเกินจอ
- Bracket และ Stage 3 Fixture ใช้ Horizontal Scroll เฉพาะส่วน
- Match Detail / Score / Developer Notes จัดเรียงใหม่สำหรับหน้าจอแคบ
- ช่องกรอกข้อมูลใช้ขนาดตัวอักษร 16px บนมือถือเพื่อป้องกัน Browser Zoom เมื่อแตะ input
- รองรับจอประมาณ 360px, 390px, 430px, Tablet และ Desktop

หาก deploy บน Netlify ให้แทนที่ deployment เดิมด้วยโฟลเดอร์เวอร์ชันนี้ทั้งหมด


## v4 — รุ่นอายุเป็นบริบทหลักของทุกหน้าการแข่งขัน

เพื่อป้องกันความสับสน หน้า operational ของระบบต้องแสดงบริบทอย่างน้อย:
- ฤดูกาล
- รุ่นอายุ/เพศ
- Stage
- พื้นที่ (อำเภอ/จังหวัด/โซน/ประเทศ)

`01-dashboard.html` มีตัวกรองรุ่นอายุและสรุปแยกรุ่น
`04-draw-setup.html` แสดง U14 ชายอย่างชัดเจน และระบุว่ารุ่นอายุต้องสืบทอดจาก Competition ไม่ให้กรอกซ้ำใน Draw
หน้าที่เกี่ยวข้องกับ Stage 1–4 และ All-Star ได้เพิ่มแถบ “บริบทของรายการแข่งขัน” แล้ว
