# ขั้นตอนการทำงานระบบจัดการแข่งขัน PMYC

```text
การลงทะเบียน
ทีม / นักกีฬา / เจ้าหน้าที่ ผ่านการอนุมัติ
        |
        v
Stage 1 ระดับอำเภอ
ล็อกรายชื่อ -> จับสลาก -> ก้างปลา -> ตารางแข่งขัน
-> รายชื่อผู้เล่น -> ผลการแข่งขัน -> แชมป์ + รองแชมป์
        |
        v
Stage 2 ระดับจังหวัด
จับสลาก -> แพ้คัดออก -> แชมป์จังหวัด
        |
        +----------------------------+
        |                            |
        v                            v
แชมป์จังหวัด                 แมวมอง / ทีมออลสตาร์
                             ค้นหานักกีฬา -> สนใจ -> คัดเลือก
                             -> เอกสารโอนย้าย -> เจ้าหน้าที่
                             -> ยืนยันรายชื่อทีม
        |                            |
        +--------------+-------------+
                       v
Stage 3 ระดับโซน
สุ่มตำแหน่งทีม -> สร้างโปรแกรมพบกันหมด 1 เลก
-> ผลการแข่งขัน -> ตารางคะแนน 3/2/1/0 -> อันดับ 1 ของโซน
                       |
                       v
Stage 4 ระดับประเทศ
12 แชมป์โซน -> 2 กลุ่ม -> อันดับ 1–2
-> รอบรองฯ -> ชิงอันดับ 3 -> รอบชิงฯ -> แชมป์ประเทศ
```
